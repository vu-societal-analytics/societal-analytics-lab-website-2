This course is designed to give VU FSW researchers all that is necessary to start 
using R in their everyday work.

Everyone is welcome, from PhD students to professors. It does not matter if you 
are a qualitative researcher that has never used R, or a quantitative researcher 
that wants to learn new topics or move out of SPSS/STATA. **All you need is to have
some experience working working with data frames!**

**When:** From February 12th to June 25th, 2027, between 9:30 and 12:30 hrs.

**Where:**  Hybrid. Onsite: Communication department. Online: Teams.

**Register:** [https://forms.office.com/e/xBY9gP3upc](https://forms.office.com/e/xBY9gP3upc)


## Itinerary
Please keep in mind that all the material builds on itself. If you are interested on a specific topic then you need to attend (know about) all the previous sessions:

1.	February 12th: Introduction to R, R-Studio, and data frames
2.	February 26th: Introduction to packages, Tidyverse, and R-Markdown
3.	March 12th: Introduction to data visualization using ggplot2
4.	March 26th: Introduction to unsupervised learning
5.	April 9th: Introduction to statistical analysis with base R
6.	April 23rd: Introduction to supervised learning 
7.	May 7th: Introduction to text as data
8.	May 21st: Introduction to text mining with tidytext
9.	June 11th: Introduction to machine learning for text with textrecipes
10.	June 25th: Introduction to basic programming with R

Depending on public holidays some dates may be moved.
